# Filer（`filer`）

[アプリの目次](README.md)

> [!NOTE]
> Filer とピッカーの基本操作は実装済みです。共有の仕組みは [アプリ間のファイル共有](../file-sharing.md) を参照してください。

Filer はユーザーのファイルを管理し、ほかのアプリからのファイル選択を受け持つ同梱アプリです。`bundled/filer/` に置き、役割 `files` を名乗ります。ファイルと共有の所有・参照の決まりは [アプリ間のファイル共有](../file-sharing.md) を参照してください。

## ファイルと共有

- ユーザーのファイルは Filer 自身の領域に置く。ほかのアプリの領域には直接触れない
- 参加した共有は、共有の名簿をもとに「共有/アプリ名」に表示する。表示名の変更は Filer 内に保存する
- 共有のルートを削除すると、Filer が共有から退出する。マイファイルにある共有参照は自分のファイルとして残す
- 共有からマイファイルへ移すときは Filer の一覧の参照を変え、内容は共有に残す。このファイルは「共有 ON」と表示する
- 共有を許すときは内容を共有フォルダに移し、参照を更新する。「共有 OFF」では内容を Filer の領域へ戻す
- アプリからの `pick` を受けて選択画面を表示し、選んだファイルの共有を承認済みの返信として渡す。選択を許可とみなす

## 画面と操作

場所は「マイファイル」と「共有」。幅が広い画面では左に並べ、狭い画面ではタブにする。上部にパンくず、上のフォルダ、新規フォルダ、読み込みを置く。一覧は名前、大きさ、更新日時、共有中の印を示す。各行のメニューから開く、名前の変更、移動、コピー、削除、書き出し、共有の切り替えを行う。名前の変更はその場の入力欄で行い、削除は画面下部で確認する。下部にはテキスト・画像のプレビューとストレージ容量を置く。

端末からの読み込みは実際のファイル選択画面を開き、複数選択に対応する。同名のファイルは `name (2).ext` のように名前を付ける。書き出しは端末のダウンロードとして保存する。ドラッグ＆ドロップとアプリを指定して開く操作は対象外とする。
